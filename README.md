# Neon Dodge 🚀

A fun and addictive browser-based dodge game with neon aesthetics!

## How to Play

- **Controls**: Arrow keys or WASD to move your glowing square
- **Goal**: Avoid the colorful falling orbs for as long as possible
- **Score**: Increases over time. Speed ramps up!
- **High Score**: Saved locally in your browser

## Features

- Smooth neon glow effects
- Increasing difficulty
- High score persistence
- Responsive controls
- Pure HTML/CSS/JS — no dependencies!

## Run It

Just open `neon-dodge.html` in any modern browser.

Or host it on GitHub Pages for easy sharing.
